# newsletter-signup

Newsletter Signup. The two-column email capture on recipe pages, authored as **Newsletter Signup**. The heading and note sit on the left. The email field, consent checkbox and button sit on the right. Below 820px the columns stack and the button spans the form.

Block classes: `newsletter-signup`. The wrapper and section are `newsletter-signup-wrapper` and `newsletter-signup-container`.

## Content

One cell:

1. A heading, such as `Love Desserts? Stay Inspired!`
2. The introduction paragraph.
3. The note, a paragraph beginning with `Please note`.
4. The consent paragraph. `Privacy Policy` is a link.

The email label, placeholder, errors, Sign Me Up button and the confirmation message are part of the block. A valid submit registers with the production signup endpoint and replaces the form with the confirmation. The block is omitted when the page is printed.
