# columns-recipe

Custom **columns** block. Purpose: recipe-method.

## Authoring (Document Authoring)

Model: `standalone`

Add the section heading and summary immediately before the block:

- `Ingredients & Directions`
- `Yields: 48 cookies`
- `Prep: 20 Min. | Bake: 11 Min. | Total: 31 Min.`

The block uses one row with two cells:

1. `Ingredients` heading followed by an unordered list.
2. `You'll Need` heading and unordered list, followed by a `Directions` heading and
   ordered list. Step images belong inside their corresponding list items. An optional
   final paragraph beginning with `Tip:` becomes the Tip disclosure on the last step.

The summary is enhanced with Bake Mode. On supported browsers, its switch uses the
Screen Wake Lock API to keep the display awake while the recipe is being followed.
