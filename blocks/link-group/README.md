# link-group

Dark band with an eyebrow and heading beside a slider of square link tiles; three tiles per page with previous/next buttons and kiss dots. Used for "Explore Recipes, Products, Activities & More" at the end of `/about/history`.

## Authoring (Document Authoring)

Model: `standalone`

| Link Group | |
| --- | --- |
| HERSHEYLAND ## Explore Recipes, Products, Activities & More | |
| picture + [About](/about) | |
| picture + [All Brands](/brands) | |

- Row 1: the eyebrow paragraph and the h2.
- Every other row is one tile: a picture and a link; the link text is the label.
- The block adds `link-group-section` to its section (dark brown band) and `footer-on-dark` to the body so the footer ribbon sits on the same colour.
