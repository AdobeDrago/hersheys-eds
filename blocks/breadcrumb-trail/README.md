# breadcrumb-trail

Custom **breadcrumb** block. Purpose: breadcrumb-navigation.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

### back (`Breadcrumb Trail (back)`)

A single back link on a full-width maroon bar with a chevron, as the VIEW ALL PRODUCTS bar at the
top of where-to-buy on hersheyland.com. One row, one cell with the link; only the first link is
used.

| Breadcrumb Trail (back) |
| --- |
| [VIEW ALL PRODUCTS](/products) |

The variant declares its own font, so it also works on pages without the Hershey theme.
